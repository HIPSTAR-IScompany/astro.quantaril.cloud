# ZeroRoomLab-manifest からの転送メモ

作成日: 2026-07-13

## 1. 受け取った方針

このリポジトリでは、AQC / IBD / SphereOS の責務分離を、以下のように整理しています。

- AQC Docker は歴史的プロトタイプとして扱う
- IBD は記憶・文脈・FAM trace・provenance を扱うバックエンド基盤として再定義する
- 哲学・神話・思想の文脈は技術実装に吸収せず、独立した文脈として保持する
